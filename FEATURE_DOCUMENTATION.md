User Story: UI Gaps: Project Icon Tooltips, Task Instructions, Custom Themes

User Story 4: Implemented as Documentation | Enhancement feature

This user story addresses the UI Gaps, interface gaps that affect how new users and project managers navigate Label Studio. 

1. Project Icon Tooltips
The three static icons displayed on each project card: representing completed annotations, skipped tasks, and predictions.
A new user seeing these icons had no way to understand what the numbers represented. These are added to each icon to make the interface self-explanatory.

2. Task Instructions Visibility
Labeling instructions can be confusing. Annotators and new users may not know where to click the button would begin labeling without guidance, leading to inconsistent results. 

3. Custom Theme Documentation
Label Studio's frontend uses a CSS variable system at web/apps/labelstudio/src/themes/default/. 
Having custom themes enhances the user experience heavily. Project manahers can sleect themes according to their project.
